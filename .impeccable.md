## Design Context

### Users

People running local shells and SSH sessions who need to read command output, keep working at the prompt, and occasionally copy or rerun a previous command.

### Brand Personality

Calm, compact, and technically precise. Follow the user's selected terminal theme rather than adding a competing visual style.

### Aesthetic Direction

Keep the terminal as the primary view. Use a restrained command history view for optional actions. The user explicitly rejected a layout that shrank the terminal and displayed the same output twice.

### Design Principles

1. Show each command's output only once at a time.
2. Preserve the terminal's full working area while commands run.
3. Reveal command history and actions when requested; return to the prompt in one action.
4. Keep copy, collapse, and rerun accessible without changing PTY behavior.
