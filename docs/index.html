01 / CAPABILITIES

工具各司其职。
工作保持连贯。

从本地调试到远端排障，把连接、文件和上下文留在同一个工作空间。

⌁

连接，有条不紊

用标签与分屏安排本地 Shell 和远端会话，按组管理常用连接。

  • 多跳 ProxyJump 与 SSH 通道复用
  • 系统 ssh-agent、密钥及多轮 MFA
  • 主机指纹确认与连接历史
▱

文件，就在手边

在 SFTP 面板浏览、编辑和传输远端文件，让文件操作贴近当前会话。

  • 上传、下载及远端编辑回传
  • 传输队列、暂停、继续与重试
  • 下载后打开文件或定位目录
✳

AI，按需加入

带上你选中的内容，让 AI 辅助解释命令、整理输出或排查问题。

  • 自选服务商与模型，自带 API Key
  • 本机会话历史、按连接分组
  • 并行聊天与可折叠思考过程
AI 功能见当前源码与版本说明 ↗

A FEW DETAILS

开始之前。

支持哪些平台？

当前提供经过本机验证的 Windows x64 安装包，依赖 Microsoft Edge WebView2。其他平台的安装包与验证范围请查看 Releases；源码包含 macOS 与 Linux 的平台适配。

AI 助手如何处理我的内容？

AI 可按需配置，不影响终端功能。请求会将你的问题、显式附带的片段和有限对话历史发送至所选服务商；自动失败诊断默认关闭。Key 存在系统凭据库，会话历史以未加密形式保存在本机。服务商可能按 API 用量收费。

AI 可以直接执行命令吗？

当前由你审阅建议并决定执行。单行命令可以插入匹配连接的终端，不自动按下回车。工具执行器、AI 自动分屏和外部 MCP 接入仍在规划中。

安装时需要注意什么？

当前安装包未签名。Windows 11 资源管理器右键菜单还需要满足身份包注册要求，注册失败不影响主程序使用。安装步骤和版本限制请查看对应发布说明。
