# wterm 功能清单（决策版）

> 产品定位：开源、轻量、设计驱动的 SSH 工作台 —— "Warp 的颜值 + Tabby 的功能 + 零订阅"
> 当前技术基线：Tauri 2 + TypeScript + xterm.js，Rust 提供终端、SSH 和 SFTP 后端。
> 本文档用途：下方「实现核验」为当前完成度的唯一权威状态；「决策」表记录产品规划与版本切分。

## 实现核验（2026-09-24，与代码逐项对照）

> **重要：下方「决策」列的 √ 只表示产品决策/计划纳入，不表示代码已完成。**
> 实际完成度以下表为准（已对照源码核验）：✅ 已完成；🟨 部分完成；❌ 未完成；⏸ 尚未纳入当前开发范围。
> 本表为唯一权威状态，取代 2026-09-20 与 2026-09-21 的历史核验记录。
> 版本基线：0.1.5。已通过 TypeScript/Rust 编译检查与 Playwright UI 回归；测试仅覆盖已有自动化场景。
