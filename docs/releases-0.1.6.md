# wterm v0.1.6

日期：2026-10-14。本次版本包含 AI 助手及本机会话历史，提供本机构建的 Windows x64 NSIS 安装包。GitHub 发布状态以对应 Release 为准。

## 更新

- 新增可配置模型服务的 AI 助手，支持 OpenAI 兼容及 Anthropic 协议、自定义地址、模型列表与系统凭据库保存 API Key；失败自动诊断默认关闭。
- AI 默认固定在右侧，可切换到左侧或终端上方并调整宽高；机器人入口与 `Ctrl+Shift+K` 可展开或折叠，后台请求持续运行。
- 会话历史保存在本机 SQLite，可查看全部会话或按连接分组、搜索。单击预览，双击或 Enter 激活；重命名、置顶、删除使用会话右键菜单。
- 多个会话可同时聊天，列表显示运行圆环；切换终端标签、预览或折叠面板不会停止回复。停止只作用于当前会话，失败或停止后可重试。
- 选中终端文字后，鼠标附近显示 AI 入口；浮动动作与右键菜单支持解释命令、排查问题、插入会话，内容带入可编辑草稿。
- 修复「插入终端」没有反应：直接写入匹配连接的本地或 SSH 终端，保持输入顺序，显示失败原因并恢复终端输入焦点；不追加回车，不广播到其他窗格。
- 回复支持 Markdown 标题、加粗、列表、引用与行内代码；长代码独立滚动，操作按钮保持可见。
- 服务商实际返回的思考文本或摘要显示为默认折叠的「思考过程」，可展开实时查看；随会话保存，支持停止与重试，不进入后续模型上下文。
- AI 与终端之间的分隔条从 6px 色块改为 1px 细线；悬停、拖动和键盘聚焦仅强调细线，保留原有拖动范围，并减少边缘留白。
- 同步中英文 README、功能清单和 AI 使用与验证说明。AI 终端执行、自动分屏与 MCP 接入仍为后续规划。

## 安装与兼容范围

- 本机安装包：`src-tauri/target/release/bundle/nsis/wterm_0.1.6_x64-setup.exe`。退出已有 wterm 后安装，重新打开即可使用新功能；原有配置和历史使用既有应用数据目录。
- 模型接口没有返回思考内容时，只显示运行状态；本次未增加官方 OpenAI Responses 推理摘要接口，也未自动调整思考预算。
- AI 生成的建议仍由用户审阅。当前没有工具执行器，检测到工具请求会明确提示未执行；「插入终端」不会自动运行命令。
- 安装程序与 Explorer 身份包未签名。Explorer 注册及 Windows 11 菜单交互继续遵循 [资源管理器集成](windows-explorer.md) 的要求。
- 真实模型服务认证、TLS、模型质量及实际远端 SSH 环境仍需目标环境验证。测试未操作用户现有终端或远程主机。

## 验证

- 前端类型检查及生产构建通过；前端逻辑测试 31/31 通过。
- Rust 后端库测试 49/49 通过，含真实本机 PTY 和回环 SSH 终端插入，以及两种模型协议的逐字节流式响应。
- 完整界面回归 102/102 通过，其中 AI 相关 54 项，思考过程新增 5 项；包含左右/上方停靠的拖动、键盘调整和尺寸恢复。界面测试使用模拟模型与 Tauri 服务。
- Explorer 原生扩展测试及 Windows x64 发布版、NSIS 安装包构建通过。
- 应用、锁文件、设置页版本显示和 Explorer 扩展版本统一为 `0.1.6`。
