## 已修复的 review 问题

| 级别 | 原问题 | 修复 |
| --- | --- | --- |
| P1 | 所有服务共用 API Key，切换地址可能发送旧服务的 Key；自动重定向可能带出认证头 | 按规范化 Base URL 和协议分别存取 Key，禁用 HTTP 重定向；旧共用 Key 不自动迁移，需重新保存 |
| P1 | 多行/控制字符命令直接粘贴无法保证不执行 | 只有单行、无控制字符且不超过 4096 字符的代码可插入，不追加回车；多行只复制 |
| P2 | 中文 UTF-8 跨网络分片时乱码 | 先缓存原始字节，按完整 SSE 行与事件解析，支持 CRLF、多 data 行 |
| P2 | 服务商流内错误或断流被当成成功 | 流内错误、无效数据、非 SSE、未收到结束标记、超长响应明确报错 |
| P2 | 多轮累积多个 system 消息，Anthropic 总使用最早指令 | 每轮仅保留当前 system 指令，历史限最近 6 轮且不超过 60000 字符 |
| P2 | 关闭/新对话后上下文或旧响应污染新会话 | 清空选中内容和历史，切换终端会话及保存 AI 配置会重置；过期片段不接收 |
| P2 | 模型列表失败时手动添加入口也隐藏；服务切换后晚到列表污染当前配置 | 手动添加始终可见；端点版本检查丢弃旧列表；首次添加选择默认模型 |
| P2 | SSH 凭据开关禁用后 AI Key 保存静默无效，删除错误被吞掉 | AI 专用凭据操作独立于 SSH 保存开关，保存/删除失败显示错误 |

## 补齐的功能

1. 真正取消 Rust 后端网络请求：停止、关闭面板、新对话、会话切换和窗口关闭均覆盖。开始确认消息解决“停止比注册更早到达”的竞态；测试观察到取消后本机 HTTP TCP 连接关闭。
2. 可选失败自动诊断：默认关闭，只分析当前活动会话的明确非零退出码；发送命令、退出码及该命令最后最多 6000 字符输出，尽力隐藏常见凭据。
3. 忙碌时不抢占：AI 正在回复、用户正在输入问题或保留选中上下文时跳过；自动诊断间隔至少 10 秒。
4. 命令块界面关闭时仍可采集诊断；无法可靠还原的光标移动/补全/控制键输入会跳过。

## 使用与边界

设置 → AI 助手：配置服务地址、对应 Key 和模型；开启“命令失败后自动诊断”才会自动发送失败上下文。敏感环境保持关闭，脱敏不能保证识别所有机密。旧版本共用 Key 需要重新保存。

本地 PowerShell 已上报退出码；远端 Shell 需要 OSC 133 集成，cmd 当前集成没有退出码。模型建议仅供人工审阅，不自动执行。

真实服务商鉴权、TLS 和模型输出质量尚未实测；未修改用户系统凭据、未提交、未推送、未发布安装包。

协议与取消实现核对参考：[Tauri 命令与 IPC](https://v2.tauri.app/develop/calling-rust/)、[Tokio watch](https://docs.rs/tokio/latest/tokio/sync/watch/index.html)、[reqwest ClientBuilder](https://docs.rs/reqwest/latest/reqwest/struct.ClientBuilder.html)。
