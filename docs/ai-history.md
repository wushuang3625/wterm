# AI 历史会话

AI 面板默认固定在应用右侧，终端在左侧，两者同时可见。顶部的左右切换图标可调整停靠方向，并记住选择。面板内的历史会话栏可收起，默认宽度为 176 像素，提供「全部会话」「按连接」两种查看方式、内容搜索和分页加载。列表与会话正文同时显示。

- 单击会话行：预览历史正文，保留当前会话的输入草稿；生成中的预览内容会实时更新。输入框保持可用，点击输入框或发送会进入所选会话，继续编辑它的草稿；历史读取失败后会解除等待状态。
- 双击或按 Enter：进入所选会话继续聊天，列表保持展开。切换会话或终端标签页后，原请求继续在后台生成并保存。
- 上下方向键：切换预览。顶部的侧边栏图标收起或展开会话栏；停靠、新对话和关闭操作也使用图标，并提供悬停说明。
- 点击工具栏 AI 头像或按 AI 面板快捷键（默认 Ctrl+Shift+K）：展开/折叠整个 AI 面板；输入问题或搜索历史时同样可用。折叠保留当前草稿，后台回复继续运行。
- 拖动 AI 与终端之间的分隔线可调整宽度，键盘可用左右方向键；顶部布局按钮切换为上方停靠，分隔线改为调整高度。位置和尺寸会保存；之前的悬浮或旧版左侧默认设置首次升级后改为右侧，之后主动选择的左右方向会恢复。
- 新对话：默认归属当前终端连接，空会话不会进入历史列表。不同会话可以同时聊天，各自使用独立的模型、上下文、请求和生成计时；同一会话的一次回复结束后才可继续发送。
- 正在生成的会话行右侧显示转动圆环，完成、失败或停止后消失；减少动态效果设置下圆环保持静止。
- 会话标题来自第一条问题。右键会话行可重命名、置顶/取消置顶或删除，操作直接作用于该行，无须先进入会话，也不会改动当前草稿。键盘可用 Shift+F10 打开菜单、方向键选择、Esc 返回列表。
- 停止按钮只停止当前会话；删除正在生成的会话也只取消该会话的请求。关闭 AI 面板或应用窗口时停止所有运行中的回复，并保存已收到的内容。
- 搜索覆盖已保存记录，较早的内容也能找到。
- 最后一次回复失败或停止时显示「重试」，沿用原问题及其附带内容，用当前服务配置重新请求。重试不重复添加问题，也保留已经填写的下一条草稿；同一会话最多同时运行一个请求。
- AI 已配置时，鼠标选中文字并松开后，在鼠标附近显示「AI ▾」，靠近窗格边缘时自动避让。点击可选择「解释命令」「排查问题」「插入会话」；选中文字后普通右键菜单也提供相同动作。菜单按内容高度调整位置，靠近窗口底部时向上展开，展开分屏菜单时也会重新计算位置。选择动作后，文字会追加到聊天框的已有草稿中，解释或排查会附上对应问题，等待用户编辑并发送。Ctrl+Shift+I 也改为准备解释问题。
- 回复支持标题、加粗、斜体、列表、引用与行内代码。代码内容单独横向滚动，操作按钮位于滚动区域外，长命令不会遮挡「插入终端」和「复制」；模型返回的 HTML 继续作为文字显示。
- AI 与终端的分隔条显示为 1px 细线，悬停或拖动时仅高亮细线；保留 6px 拖动区域，减少边缘留白，左右及上方停靠一致。
- 模型返回思考片段时，每条回复顶部显示默认折叠的「思考过程」，用户可随时展开或收起。展开后实时更新，正式回复在其下方显示；完成、停止、失败和当前窗口内切换会话会保留展开选择，重新打开应用时恢复默认折叠。过程较长时独立滚动，代码仅供阅读。
- 思考文本随该回复保存在本机历史中，停止或失败保留已经收到的部分；重试清空旧过程并重新生成，默认折叠。思考与正式回复共用 100000 字符上限；后续问答只发送正式回复，思考文本不加入模型上下文。没有返回思考内容的模型只显示原有状态提示，不出现空折叠区。

### 接口兼容范围

接收 OpenAI 兼容接口已有的 `reasoning_content` / `reasoning` 字符串，以及 Anthropic 的 `thinking_delta.thinking`；同一片段同时包含思考和正文时分别保存。签名和加密思考内容不展示。当前功能负责展示已返回的内容，不自动调整模型的思考参数或预算。

[DeepSeek 接口文档](https://api-docs.deepseek.com/guides/thinking_mode/)说明了思考与正文的独立返回方式；[Claude 流式文档](https://platform.claude.com/docs/en/build-with-claude/streaming)说明了思考片段及签名事件。官方 OpenAI 的推理摘要使用 Responses API；当前助手的 OpenAI 兼容协议仍走 Chat Completions，本次未新增 Responses 接入。[OpenAI Docs](https://developers.openai.com/api/docs/guides/reasoning)

## 连接归属

每个保存的 SSH 连接具有稳定 ID，旧配置在读取时自动补齐；连接改名或移动分组不会使历史失联。迁移和保存通过进程间文件锁串行处理，避免多个应用窗口首次启动时分配不同标识。同一连接的多个终端标签共享一个会话组。本地终端和通用聊天分别归组；临时 SSH 连接按主机、端口、用户名和跳板区分。

打开历史不会自动建立 SSH 连接。删除连接配置后历史仍然保留，并显示「已删除」。历史记录保留原连接目标信息；更改连接地址不会把旧会话的命令关联到新主机。

只有当前可输入终端的连接 ID 和目标信息都匹配，才允许「插入终端」。预览中点击符合条件的命令会进入该会话再插入；不同连接或不安全的代码会显示不可用原因。插入仍只接受单行且无控制字符的命令，不追加回车，也不广播到其他终端。

点击插入后会返回终端输入视图、清除选择并滚到当前输入位置。插入通过独立的原生命令直接写入对应终端，与键盘输入保持顺序；根据终端状态保留括号粘贴模式。SSH 原始通道与复用通道均在实际发送字节后返回确认，关闭通道时返回错误，而非仅确认进入待发送队列。确认后显示「已插入终端，按 Enter 执行」；等待期间按钮暂时禁用，写入失败会显示具体错误。等待确认期间切换窗格不会在完成后抢回焦点。插入反馈按消息与代码块保存，预览激活、配置刷新或重新显示会话后仍会保留。

## 保存与恢复

完整对话、实际附带的终端片段、已保存会话的草稿、模型信息和生成状态保存在本机。发送给模型的上下文独立裁剪为近期完整问答，历史正文不会随之删除。停止或失败的部分回复可以回看，不作为完整问答发送给模型。

默认文件为系统配置目录下的 `wterm/ai-history.sqlite3`，Windows 为 `%APPDATA%\wterm\ai-history.sqlite3`。数据库独立于偏好设置文件；API Key 继续使用系统凭据库，不写入历史配置。SQLite 的 `-wal`、`-shm` 文件属于正在使用的数据库，运行时不要单独移动或删除。

流式回复定期保存，完成后立即提交；窗口正常关闭前停止请求并等待保存。重新打开会话后保留未完成的正文。历史读取或写入失败会显示错误，可重试，内容保留在当前窗口；关闭时仍未保存会明确提示。多个窗口编辑同一会话时使用版本检查，拒绝过期写入，避免覆盖较新的内容。仅查看、预览或进入会话不改动正文版本。

## 实现入口

- `src/ai-panel.ts`：会话选择、预览、独立流式请求、后台生成、取消和连接匹配。
- `src/ai-history.ts`：完整记录、模型上下文转换、串行保存和版本衔接。
- `src/ai-history-view.ts`：侧边栏、运行圆环、会话右键菜单与键盘交互。
- `src/ai-selection.ts`：终端选中内容动作、浮动入口和待发送问题。
- `src/ai-helpers.ts`：安全的回复格式渲染与单行命令检查。
- `src/terminal.ts`、`src-tauri/src/webview.rs`、`src-tauri/src/session.rs`、`src-tauri/src/ssh.rs`：输入队列、原生插入、PTY 写入与 SSH 通道确认。
- `src/ai-icons.ts`、`src/ai-window.ts`：工具栏图标和窗口布局。
- `src-tauri/src/ai.rs`：按窗口和请求 ID 隔离的并行模型请求及取消。
- `src-tauri/src/ai_history.rs`：SQLite、分页搜索、版本检查和恢复。
- `src-tauri/src/profiles.rs`：稳定连接 ID 的迁移和持久化。

实现参考：[rusqlite](https://docs.rs/rusqlite/0.40.2/rusqlite/)、[UUID](https://docs.rs/uuid/1.26.1/uuid/)、[Rust 文件锁](https://doc.rust-lang.org/std/fs/struct.File.html#method.lock)。
